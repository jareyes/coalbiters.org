\small\noindent\textsf{\textbf{Finding the Ballroom.}}
From the ground entrance, walk past the stairs down to the main bar and dining room. The stairs to the ball room are beyond that
and a little to the right. You will walk down a short hallway that opens up to a large event space directly over the main dining
room below. There will be a dance floor in the middle of the room and a bar to the right side of the entrace.
You should set up on a table to the left of the entrace inside the room.
\normalsize

\vskip 5pt
\begin{itemize}
\item[$\bullet$] \textsf{Set up for the event}
  \begin{itemize}
  \item Plug in each transmitter to one of the tablets
  \item Set each transmitter to a different channel
    \begin{itemize}
    \item Set channel 1
    \item Set channel 2
    \item Set channel 3
    \end{itemize}
  \item Use the PIN \textsf{1234} to unlock each tablet.
  \item Open Spotify on each tablet
  \item Navigate to \textsf{Your Library $\to$ Downloaded $\to$ Coalbiters Disco \#1: Disco}
    \begin{itemize}
    \item Select \textsf{Coalbiters Disco \#1: Low}
    \item Select \textsf{Coalbiters Disco \#1: Medium} \small{\textit{separate tablet}}
    \item Select \textsf{Coalbiters Disco \#1: High} \small{\textit{separate tablet}}
    \end{itemize}
  \item Hit play
  \item Using the long button on the side of each tablet, turn up the volume to maximum
  \item Using a headset, verify that music is playing on all three channels
  \item Put up the check-in/out posters as appropriate
  \item Put up the ticket QR posters as appropriate
  \end{itemize}
  \vskip 5pt
\item[$\bullet$] \textsf{Set up a tablet for check-in}
  \begin{itemize}
  \item Get the Wi-Fi credentials from David or Lisa
  \item Enable Wi-Fi on one tablet
  \item Navigate to \textsf{www.eventbrite.com/signin}
  \item Enter the email address \textsf{admin@coalbiters.org}
  \item Enter the password \textsf{Vucadby1!}
  \item In the accounts menu, select \textsf{Manage my events} \textbf(or) go directly to \textsf{www.eventbrite.com/organizations/home}
  \item Click on \textsf{Events} from the vertical icon menu on the left
  \item Click on \textsf{Claremont Pride Silent Disco}
  \item Scroll down and click on \textsf{Manage Attendees}
  \item Select \textsf{Check-in}
  \end{itemize}
  
  \vskip 5pt
\item \textbf{6:00PM} Restart the music on each tablet

  \vskip 5pt
\item[$\bullet$] Checking Guests In
  \begin{itemize}
  \item If needed, ask them to purchase a ticket using the QR code on the poster or by going to \textsf{coalbiters.org}
  \item Verify their name in Eventbrite and click \textsf{Check in} in the \textsf{Status} column \textbf{or}
  \item Give them them a headset for each ticket purchased
  \end{itemize}
\end{itemize}
